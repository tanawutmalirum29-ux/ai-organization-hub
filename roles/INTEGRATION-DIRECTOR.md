# Legacy Integration Director — V2 compatibility
บทบาท Integration Director แบบรายงานตรง CEO ถูกแทนที่ด้วย [DCEO-DELIVERY](DEPUTY-DELIVERY.md). DCEO-DELIVERY เป็น Integration Owner และผู้เซ็น Delivery คนสุดท้าย; CEO เป็นผู้ Merge main. ผู้ช่วย Integrator ที่ตั้งเพิ่มต้องรายงานตรง Delivery เท่านั้นและไม่มีสิทธิ์เซ็นแทน.

ห้ามใช้บทบาทเก่านี้เป็นสายรายงานคู่ขนานหรือช่องทางสั่งข้ามหัว. ดู [V2](../docs/V2-GOVERNANCE.md).
