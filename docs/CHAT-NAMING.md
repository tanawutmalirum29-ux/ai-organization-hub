# Chat Title Convention — Governance V2 (บังคับเสนอชื่อแชทตามตำแหน่ง)

**กฎนี้ใช้กับ AI ทุกแชทของโครงการ Ant Kingdom รวมถึง CEO, Deputies, Directors, Leads, Engineers, Assistants และ Roster Steward.** ต้องเสนอชื่อ **ทันทีหลังได้รับคำสั่งแต่งตั้งที่มี `role_id` จริง** แม้ยังไม่ได้เริ่มงานเกม.

## มาตรฐานชื่อ
```text
ANT | <ROLE_ID>
```

`<ROLE_ID>` ต้องเป็น Role ID ที่ได้รับจาก **GitHub Appointment Issue ของตัวเอง**, คงตัวพิมพ์ใหญ่/ตัวเลข/ขีดกลางตามจริง ไม่สร้างชื่อหรือเลขเอง ไม่ใช้ Role class กว้าง ๆ (`ENGINEER`, `TEAM-LEAD`) หากแต่งตั้งเป็นรหัสรายคน (`VIS-E1`, `VIS-TL1`). ถ้ามีหลายคนในตำแหน่งระดับเดียวกัน **ต้องใช้รหัสเฉพาะคนที่ไม่ซ้ำ**.

| Role / ตัวอย่าง Role ID ที่ได้รับจริง | ชื่อแชทที่ต้องเสนอ |
| --- | --- |
| `CEO` | `ANT | CEO` |
| `DCEO-DELIVERY` | `ANT | DCEO-DELIVERY` |
| `DCEO-SYS` | `ANT | DCEO-SYS` |
| `DCEO-EXP` | `ANT | DCEO-EXP` |
| `DCEO-PLAT` | `ANT | DCEO-PLAT` |
| `DCEO-QA` | `ANT | DCEO-QA` |
| `VIS-DIR` | `ANT | VIS-DIR` |
| `VIS-TL1` | `ANT | VIS-TL1` |
| `VIS-TL2` | `ANT | VIS-TL2` |
| `VIS-E1`, `VIS-E2` | `ANT | VIS-E1`, `ANT | VIS-E2` ตามคน |
| `SYS-DIR2` (ตัวอย่างสมมติ) | `ANT | SYS-DIR2` |
| `EXP-ASST1` (ตัวอย่างสมมติ) | `ANT | EXP-ASST1` |
| `ROSTER-STEWARD-01` (ตัวอย่างสมมติ) | `ANT | ROSTER-STEWARD-01` |

**เมื่อ Round เปลี่ยนแต่ Role ID เดิมไม่เปลี่ยน ไม่ต้องเปลี่ยนชื่อแชทตามรหัส Round หรือชื่อ Task.** เมื่อโอนตำแหน่งและมี `TRANSFER_ACK` ใหม่ ให้เสนอชื่อใหม่จาก Role ID ปัจจุบัน. ถ้ายังไม่รู้ Role ID → `NEEDS_APPOINTMENT`, ห้ามเดาชื่อ.

## เมื่อได้รับแต่งตั้ง
1. อ่าน GitHub Appointment Issue + [Role Start](ROLE-START-HERE.md) + [Activation Packet](ACTIVATION-PACKET.md); ยืนยัน `ROLE_ID` และ `DIRECT_PARENT` จริงก่อน.
2. **แสดงบรรทัดชื่อแชทแนะนำให้ Owner เห็นเป็นอันดับแรกในคำตอบรับ** โดยใช้ค่าจริง: `ชื่อแชทแนะนำ: ANT | <ROLE_ID>`. บรรทัดนี้อยู่ **นอก** ข้อความส่งต่อ 3 บรรทัด เพื่อไม่ปนกับ `Next recipient`.
3. ตรวจว่ามีเครื่องมือ **แก้ชื่อบทสนทนา ChatGPT จริง** หรือไม่. ถ้ามีเครื่องมือที่ใช้ได้และผู้ใช้อนุญาต ให้ใช้และรายงานตามผลจริง. **ถ้าไม่มี (เช่น GitHub Connector อย่างเดียว) ต้องเพียงเสนอชื่อ** และแจ้งสั้น ๆ ว่า Owner ต้องเลือก Rename เอง. ห้ามอ้างว่าเปลี่ยนชื่อแชทสำเร็จทั้งที่ไม่มีเครื่องมือ.
4. โพสต์ `APPOINTMENT_ACK` ใน Issue ของตัวเอง พร้อม `suggested_chat_title`, `ROLE_ID`, `DIRECT_PARENT`, `SKILL_READY/SKILL_GAP` และหลักฐานตามกฎเดิม.
5. หลัง ACK ให้ส่งข้อความสั้น 3 บรรทัดตาม [Relay Templates](RELAY-TEMPLATES.md) ส่งไปยัง **หัวหน้าตรงเท่านั้น**. ชื่อแชทเป็นข้อมูลจัดระเบียบ ไม่ใช่คำสั่งเริ่มเกม/สิทธิ์เพิ่มเติม.

## หน้าที่ของหัวหน้าที่แต่งตั้ง
- Issue แต่งตั้งต้องมีช่อง `suggested_chat_title: ANT | <ROLE_ID>` ซึ่งคำนวณจาก Role ID ของคนนั้นจริง.
- ในข้อความที่ให้ Owner ส่งแชทลูกน้อง ใส่ชื่อแชทไว้ใน **เนื้อหา Issue หรือบรรทัดคำสั่งอ่านกฎ** ตามความเหมาะสม โดยรักษาข้อความส่งต่อไม่เกิน 3 บรรทัด.
- เมื่อรับ `APPOINTMENT_ACK` ตรวจว่าชื่อที่เสนอและ Role ID ตรงกัน; ถ้าไม่ตรงให้แก้ก่อนรับรอง ไม่สร้างชื่อซ้ำจาก Role class ของตำแหน่ง.
- Roster Steward บันทึก `suggested_chat_title` ตาม Role ID เมื่อสร้างรายการจริง; **การมีชื่อในทะเบียนไม่ใช่หลักฐานว่ามีแชทหรือเปลี่ยนชื่อแชทได้แล้ว**.

## ความสามารถที่ต้องไม่กล่าวเกินจริง
การกำหนดกฎใน GitHub **ไม่สามารถสั่งให้ ChatGPT เปลี่ยนชื่อแชทได้อัตโนมัติ** และไม่ได้สร้างแชทขึ้นมาเอง. ในระบบนี้ชื่อแชทเป็น **ข้อเสนออัตโนมัติที่ AI ต้องพิมพ์ให้ถูก**, การ Rename ใน UI ต้องทำโดย Owner หากไม่มีเครื่องมือรองรับ. เมื่อการตั้งชื่อทำไม่ได้ไม่ถือเป็น Blocker ของงานพัฒนา แต่ต้องรายงานตามจริง.
